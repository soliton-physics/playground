Questions

Questions, answered

Is Soliton free?

Yes. The playground, the sandbox and every simulation are free to use, for anyone: students, teachers, schools and the simply curious. Nothing to sign up for.

Can I build my own simulations?

Yes. The sandbox lets you draw balls, boxes, any polygon, platforms, inclines and walls, join them with ropes, rods, springs and pins, or start from a sun and planets and throw in a comet. There is a circuit builder for batteries, resistors, capacitors, inductors and diodes, a wave lab for mixing waves, and a maths mode where you type any function. Everything you build can be shared as a link.

Which syllabus does it cover?

Every chapter of NCERT physics for class 11 and class 12, from motion in a straight line to semiconductor electronics. It serves CBSE and state boards, and the same physics JEE and NEET ask about.

Do students need to install anything?

No. It runs in any modern browser, on a laptop, a phone or a smartboard. Share a link and it opens exactly the scene you showed.

Can I use it on a projector in class?

Yes. Press T for projector mode: text, arrows and lines grow bigger and bolder so the back row can read them.

How is it different from an animation or a video?

Nothing is pre-recorded. A physics engine computes every force, path and graph as you watch, and the result is set beside the textbook's formula, so students can see the formula come true and change the numbers themselves.

Can I put the simulations in my own website or app?

Yes. Any simulation can be embedded, and the engine itself is on npm as @soliton-physics/engine and on PyPI as soliton-physics, free to use including commercially.
